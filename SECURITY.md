# Security and responsible disclosure

Do not commit credentials, private contact details, personal identifiers,
unpublished portfolio material, private messages, or third-party confidential
assets. If sensitive material is found, do not reproduce it in an issue or pull
request; remove it locally and contact the maintainer through the private GitHub
security channel if enabled.

This profile repository is not an identity-verification, recruitment, or contact
service. The public-display and asset boundary is documented in
[`PRIVACY_AND_DATA_BOUNDARY.md`](PRIVACY_AND_DATA_BOUNDARY.md).
