# Portfolio pipeline

## Purpose

The repository renders a public-safe visual summary of Manu Faujdar's work.
Project facts and technical claims belong in linked repositories; this pipeline
only summarizes approved public categories and links.

## Data flow

portfolio.json -> scripts/render_portfolio.py -> assets/portfolio-status.svg

README.md embeds the generated SVG assets and links to selected public
repositories. The constellation graphic is a checked-in visual asset and is
not generated by the Python script.

## Code responsibilities

- portfolio.json is the small source data file.
- render_portfolio.py loads JSON, escapes text/color values, positions cards, and writes SVG.
- assets/portfolio-status.svg is generated output and should change only when source data or renderer changes.
- The GitHub Actions workflow refreshes the visual when declared inputs change.

## Local verification and privacy

Run the renderer, inspect the SVG diff, and verify that README links point only
to intentionally public repositories. Do not add private portfolio names,
personal contact data, credentials, or unreviewed status claims.

Choose a license if reuse is intended. Keep generated assets reproducible and
preserve a human review step for public-facing claims.
