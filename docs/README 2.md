# Profile repository documentation

This repository is a public profile and portfolio renderer with a mixed-license
boundary:

- `LICENSE` — MIT for source code and scripts.
- `LICENSE-CONTENT.md` — CC BY 4.0 for original profile copy and artwork.
- `COPYRIGHT.md` — scope, exclusions, and attribution notes.
- `PRIVACY_AND_DATA_BOUNDARY.md` — public-display and personal-data rules.
- `THIRD_PARTY_NOTICES.md` — linked projects, marks, fonts, and asset review.

Before editing, verify that every claim is intentionally public and supported by
the owner's current profile evidence. Before redistribution, inspect each asset
and preserve the appropriate attribution.
