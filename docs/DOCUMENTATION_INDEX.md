# Documentation index

This repository is the public profile and portfolio renderer, not a product
runtime. It keeps project details in linked repositories and serves as a visual
map.

## Authoritative documents

- README.md: public profile and project links.
- portfolio.json: public-safe domains, captions, signals, and colors.
- scripts/render_portfolio.py: deterministic SVG rendering logic.
- .github/workflows/refresh-portfolio-visual.yml: refresh automation.
- docs/portfolio-pipeline.md: data flow, maintenance, and privacy boundary.
