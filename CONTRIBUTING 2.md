# Contributing

Keep contributions limited to public profile presentation, renderer behavior,
accessibility, and reproducible portfolio metadata. Verify public claims against
the owner's current profile evidence before proposing them.

Do not add private contact details, credentials, unpublished work, third-party
personal data, or assets whose reuse rights are unclear. Explain the scope of
any code change, identify the license boundary it affects, and run the smallest
available renderer or asset checks before opening a pull request.

Contributions do not grant permission to use the profile, identity, trademarks,
or linked projects for endorsement, impersonation, or unrelated marketing.
