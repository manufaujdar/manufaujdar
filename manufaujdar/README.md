**[Live demo](https://h6s-1a31f9730cd85b-headlessstack.wix-site-host.com)**

## Display preferences

Quick navigation (Menu or Ctrl/Cmd K) includes Light, Dark and System theme
selection, plus Native/Smooth scrolling. The header theme button cycles all
three modes. Browser storage failures still apply appearance to the current
page and report that the preference could not be saved.

The optional desktop Home/Work enhancement uses MIT-licensed
[Lenis 1.3.26](https://github.com/darkroomengineering/lenis/tree/v1.3.26).
Touch, other pages and device reduced motion retain native scrolling. Dialogs,
selects and textareas keep their native scrolling. The single Lenis animation
loop is destroyed when disabled or when leaving the page. No GSAP or second
smooth-scroll library is needed.
